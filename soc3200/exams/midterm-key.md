# SOC 3200 — Midterm Examination — Answer Key (Instructor Material)

**Do not distribute to students.**

Each question is marked for what a full-credit answer must *contain*, not for a single "correct" script.
Award points for the presence of the required elements and for evidence discipline; deduct for
fabrication and for tier-blurring.

## Part A — 12 points each

### A1. Stratification and life chances

| Points | Full-credit answer must contain |
|---|---|
| 3 | A correct definition of *stratification* as durable, ranked layering with unequal access to resources and life chances |
| 3 | A correct definition of *life chances* (Weber): the probability of obtaining goods, positions, and security given one's place |
| 3 | *Structure* identified as a ranking that operates beyond individual intention, tied to the Ep 9 budget-crisis fact |
| 3 | A visible separation of documented fact ("the published summary states…") from interpretation ("my reading is…") |

**Common errors:** collapsing stratification into "inequality of income"; treating life chances as mere
luck; asserting the crisis is "the students' fault" without naming structure.

### A2. Marx and Weber

| Points | Full-credit answer must contain |
|---|---|
| 3 | Marx's class as a relationship to the means of production (owners vs. those who sell labour) |
| 3 | Weber's three axes kept separate — class (market), status (honour), party (power) |
| 3 | Both applied to a *specific, named* beat, with each lens made to reveal something distinct |
| 3 | An honest statement of what each lens *hides*, not a "both are valid" hedge |

**Common errors:** merging status into class ("it's all money"); scoring the theorists instead of using
them; no anchor to an actual beat.

### A3. Wealth versus income

| Points | Full-credit answer must contain |
|---|---|
| 3 | Income defined as a flow and wealth as a stock (assets minus debts), correctly contrasted |
| 3 | The gap explained through accumulation, not earnings — stocks outgrow flows |
| 3 | At least one of assets/debt used to show *why* the wealth gap dwarfs the income gap |
| 3 | The Ep 2 documented fact (Rashida struggling financially) anchored, and the scene's *flow* problem distinguished from a *stock* problem |

**Common errors:** using "wealth" and "income" interchangeably; explaining the gap with income alone;
treating a flow problem as if it were a stock problem.

### A4. Distinction

| Points | Full-credit answer must contain |
|---|---|
| 3 | *Cultural capital*, *distinction*, and *habitus* each defined distinctly (not merged) |
| 3 | The "taste never names money" mechanism identified in the headliner fight |
| 3 | The Ep 3 documented fact (Deborah securing a headliner) anchored |
| 3 | Documented fact and interpretation explicitly separated at least once |

**Common errors:** defining all three terms with one sentence; claiming the fight is "just about taste"
without finding the class; no tier separation.

### A5. Race and formation

| Points | Full-credit answer must contain |
|---|---|
| 3 | *Racial formation* defined as a sociohistorical process — categories made, inhabited, transformed |
| 3 | *Racial stratification* distinguished from it (the ranking vs. the making of the category) |
| 3 | The Ep 7 documented fact (Kojo in the diaspora argument) anchored |
| 3 | The argument read as *formation* — a category being made/contested — not just culture talk |

**Common errors:** using "racial formation" as a synonym for "race" or "racism"; treating race as fixed
and natural; no anchor.

## Part B — 40 points

| Points | Full-credit answer must contain |
|---|---|
| 8 | A specific, named beat, accurately described, with documented facts clearly separated from readings |
| 8 | Marx applied to the beat, doing distinct work (ownership, labour, surplus) |
| 8 | Weber applied, doing distinct work (class, status, party kept apart) |
| 8 | Bourdieu applied, doing distinct work (capital, distinction, habitus) |
| 4 | A defended judgement: which dimension best explains the ranking, with reasons |
| 4 | The honest limit named — what the beat cannot show — stated about the claim, not as a hedge |

**Common errors:** describing the episode instead of reading a beat; using the three theorists as
synonyms; declining to judge ("all three matter equally") without argument; no honest limit.

**Marker's note.** The tier discipline is worth enforcing here as much as the theory. A well-read answer
that blurs documented fact and interpretation should lose the evidence points even if the theory is
sound; a modest answer that keeps the tiers clean should be rewarded.
