# Homework 1 — Your own public issue

**Due:** start of Session 2 · **Length:** 1 page · **Weight:** counts in the homework average (lowest two dropped)

## Task

1. Identify one thing in your life that felt like a *personal trouble* (a problem you thought was yours alone).
2. Using C. Wright Mills's idea from Session 1, restate it as a possible *public issue* — a problem that is
   also true for many people because of how society is arranged.
3. Answer, in a compact block:
   - The personal version (what it felt like from inside).
   - The public version (how a sociologist would restate it).
   - One question you would need to answer to know whether the public version is really true — something
     you could actually find out, not a feeling.

## Sources

- C. Wright Mills, *The Sociological Imagination* (1959), ch. 1 (from Session 1)
- The reference site, for the method: https://joenobody-ai.github.io/different-world-notes/v2/
